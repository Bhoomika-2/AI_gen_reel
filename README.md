## 🚀 Running Locally

### 1. Install Dependencies
```bash
npm install
```

### 2. Preview in Remotion Studio
```bash
npx remotion studio src/index.jsx
```

### 3. Render Master Video
```bash
npx remotion render src/index.jsx SaiIntelliverseReel sai_intelliverse_promo_reel.mp4
```

### 4. In-Browser Player
Open `video_preview.html` directly in any web browser to view the video with custom looping and timeline playback controls.
